This mod adds a range of custom eye color genes. Vanilla factions that don’t already have custom eyes will get eye colors based on their unique traits.

It includes an autopatcher that gives eyes to xenotypes without existing patches. It’s not perfect, but it makes sure everyone has eyes. There’s also an autopatcher for baseliners. Both features can be turned off in the settings.

Eyes will not show up in genepacks

**Recommend Mods**  
Recommended to use this mod with [Camera+](https://steamcommunity.com/sharedfiles/filedetails/?id=867467808) as the eyes will be small and hard to see the details.
